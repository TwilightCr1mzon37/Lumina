About me

Hi! I'm Christian Jay D. Fundal, a first-year Bachelor of Science in Computer Science student at Ateneo de Davao University. I have a passion for software development, user interface design, and creating meaningful digital experiences. Through Lumina, I sought to combine clean architecture, modern design principles, and practical functionality into a project that reflects both my technical skills and my commitment to continuous learning.

About this project

Lumina was created as a final project for the Introduction to Computing course, designed to bring together multiple programming concepts into a single, intuitive, and visually engaging web application. More than just an academic requirement, it became an opportunity for me to apply clean coding practices, modular software architecture, and user-centered design principles. Building Lumina strengthened my technical skills in HTML, CSS, and JavaScript while teaching me the importance of planning, maintainability, accessibility, and creating software that balances functionality with a meaningful user experience.
